Machine Learning Models

regression
  • 'linear'A linear regression model that assumes a straight-line relationship between independent variables and the target.
  • 'ridge'A linear model that adds L2 regularization to penalize large coefficients.
  • 'lasso'A linear model that adds L1 regularization, encouraging sparsity in the coefficients.
  • 'logistic'Used for binary outcomes, it models the probability of the target as a logistic function.
  • 'mlp'A multi-layer perceptron neural network, suitable for non-linear regression tasks.
  • 'svr'Support Vector Regression models continuous outputs by finding a function that approximates the data within a specified margin.
  • 'decision_tree'Uses a tree-like model of decisions for predicting continuous values.
  • 'random_forest'A collection of decision trees that work together to improve accuracy by reducing overfitting.
  • 'gradient_boosting'Builds trees sequentially, where each tree tries to correct the errors of the previous one.
  • 'ada_boost'Combines multiple weak learners, focusing more on samples that were misclassified by previous learners.
  • 'knn'K-Nearest Neighbors regression predicts based on the average of the nearest data points.
classification
  • 'logistic'Models the probability of the target being one class versus the other using a logistic function.
  • 'decision_tree'Classifies data by learning simple decision rules derived from the feature values.
  • 'svc'Support Vector Classification aims to find the best boundary between classes by maximizing the margin.
  • 'random_forest'A collection of decision trees for classification that provides more stability by reducing overfitting.
  • 'gradient_boosting'Builds classifiers sequentially, focusing on correcting the errors of the previous classifiers.
  • 'ada_boost'Combines several weak classifiers to form a strong classifier by focusing on previously misclassified points.
  • 'knn'K-Nearest Neighbors assigns a class based on the majority class among its nearest neighbors.
  • 'mlp'A neural network for classification tasks, capable of learning non-linear decision boundaries.
